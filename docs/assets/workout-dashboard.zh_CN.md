# 运动看板

应用直接启动到独立设计的 240 × 320 马赛克运动界面，复用 BSP，不复用硬件测试
菜单或演示外壳。保持默认 8 MB 分区布局，通过 NVS 保存网络设置和一份经过校验
的运动快照及各 AI 平台独立的快照，无需文件系统分区。

设备所有页面使用效果图对应的固定浅色配色：浅色背景、浅绿面板、深绿文字与马赛克
标记。电脑上的浅色或深色外观不会改变固件配色。

菜单包括运动看板、AI 用量、网络配置、立即同步和 Codex 任务。在网络页长按下键

运动和 AI 快照。

三颗按键都是实体控制，屏幕不显示模拟按钮。空闲 30 秒后背光降至 20%，60 秒后
熄屏；第一下按键仅唤醒屏幕，不执行页面操作。启用 Wi-Fi Modem 节能和自动轻睡眠；
整板功耗和 USB 连接影响需要真机测量。不启动音频和蓝牙服务。

## 配置 Wi-Fi 和接口

没有保存设置时，设备自动开启临时 WPA2 热点。长按确定进入菜单，选择**网络与
接口**，再选择**添加配置**查看配网码。已有设置会自动重连，重新配置也从此处进入。

1. 手机相机扫描第一个二维码加入设备热点。屏幕同时显示本次会话的热点名和随机
   12 位密码，不支持自动加入时可手动连接。
2. 按上、下或确定显示第二个二维码。手机保持连接设备热点，再扫描该码打开本地
   配置页面。
3. 填写 2.4 GHz Wi-Fi 名称、密码和后端地址。开放网络可留空密码。SSID 限制
   32 个 UTF-8 字节；非空密码限制 8–63 字节。设备使用独立的 16 px 网络字体显示
   ASCII 和字体包含的中文。未覆盖字符（包括表情）明确显示 Unicode 编码，避免缺字方框。
4. 使用电脑可访问的局域网地址，例如 `http://192.168.1.20:8000`，也可以填写完整
   `/api/workout` 地址。基础地址自动补上 `/api/workout`。不要使用 `localhost`
   或 `127.0.0.1`。支持 IPv4 / DNS 主机、可选端口和 HTTP / HTTPS；不接受 IPv6
   字面量、URL 内嵌凭据、查询参数和片段。
5. 等待连接并获取 IP。设备验证候选网络最多 20 秒，成功后才整体保存配置。
   失败保留原配置并尝试重连。APSTA 连接路由器时可能切换无线频道，手机可能短暂
   断开热点；再次提交前先看设备上的结果。

后端需要监听局域网接口，即 `0.0.0.0` 而非仅回环地址；路由器和防火墙需要允许
设备访问服务器。保存网络设置只代表 Wi-Fi 连接成功，数据同步结果单独显示。
HTTPS 使用 ESP-IDF CA 证书包验证证书，必要时先通过 `pool.ntp.org` 同步时钟。

成功保存后 10 秒关闭配网；退出配网页立即关闭；没有完成时 10 分钟超时关闭。
本地配置页要求第二个二维码携带的随机会话令牌。不记录密码或二维码参数，也不
将它们编译进固件。无需公共网站或手机 App；未实现自动弹出认证门户。

## 已保存的网络与服务器

配网成功后分别保留最多 5 个 Wi-Fi 和 5 个完整、规范化的服务器 URL。相同 SSID
更新密码，相同 URL 复用已有条目。列表已满时，新增条目替换最早加入且非当前选择
的条目。获取 IP 并成功保存整个历史 Blob 后，才启用新配置。

在**网络与接口**中选择**切换 Wi-Fi**或**切换服务器**。上下移动高亮行，确定
切换，长按确定返回。当前选择有独立文字标记。长名称在列表中省略，底部滚动显示
完整内容。更换 Wi-Fi 保持服务器选择，更换服务器保持 Wi-Fi 选择。选择当前
服务器会重新请求数据，不重复写入选择；离线时也可以选择服务器。

开机、Wi-Fi 断开或丢失 IP 时，工作任务先尝试上次成功的 Wi-Fi，再尝试其余
已保存网络；每个网络最多等待 20 秒获取 IP。全部失败后暂停 30 秒，再开始下一轮。
配网热点开启期间暂停自动轮询，避免意外切换无线频道。手动选择 Wi-Fi 只进行
一次 20 秒尝试；连接失败或选择保存失败时恢复原选择，并继续自动恢复。自动恢复
的连接在保存失败时仍可使用，后台每 30 秒重试写入选择。

在运动首页遇到断线或完成一轮尝试仍全部失败时进入连接状态页，提供重试和添加
配置入口；其他页面和背光
空闲策略保持可用。服务器失败不会轮换 Wi-Fi。获取 IP 不代表能访问互联网；
本版本没有独立的互联网探测，也不会自动切换服务器。服务器选择同时切换运动、
Codex 和 GLM 接口，隐藏旧来源数据并重新请求。

带版本和校验和的 `profiles` NVS Blob 保存两类历史与选择索引。该 Blob 不存在
时，在内存中继承旧 `network` 单组配置，下次改变选择或成功配置时写入新 Blob。
历史损坏或版本不支持时显示存储失败，不静默回退到旧设置。运动 / AI 缓存与分区
格式保持不变。旧键保留用于迁移；旧固件无法读取新历史，可能仍看到旧单组配置。
明确清除设置会删除两个键及全部历史，保留缓存。升级前已被覆盖的网络无法恢复。

## 数据、离线和失败行为

联网后每五分钟请求一次 `GET /api/workout`，临时失败每 30 秒重试。HTTP、解析
和 Flash 写入在工作任务中执行，与按键和 UI 处理分离。响应限制 4 KB、10 层嵌套，
并限制 JSON 复杂度；只接受成功信封和完整、有效的月/周汇总。月分段为 1–7 日、
8–14 日等日期区间，不是 ISO 自然周；周分段为周一至周日，可能跨月或跨年。

只保留距离、时长、配速、目标、分段、日期和上游更新时间。无效 JSON、请求失败
或比现有快照更旧的响应不会覆盖上次有效数据。零跑量、零目标和不可用电量读数
均有明确的显示降级。

快照包含格式版本、来源标识和 CRC。单个 NVS Blob 提交按 NVS 事务语义保留中断
写入前的数据。开机先读取快照，再请求新数据；相同响应不重复写入，缓存写入失败
会在后续同步重试。为满足关机、断网后的使用要求，快照有意不设置过期删除时间；
日期保持原值，屏幕显示离线/旧数据和上次同步时间。运动只保存一份快照，不随历史增长。
更换服务器后暂时隐藏原来源数据，直到新来源请求成功；清除网络设置仍保留快照。

固定中文文案使用经过验证的字符集，包括标点。文本绘制明确选择 12 / 16 / 20 px
子集字体，大数字使用原创 35 px 像素字体。动态网络名称使用放在 Flash 中的独立
16 px 字体，缺字明确显示 Unicode 编码。见[字体资产说明](../../assets/README.zh_CN.md)。

## AI 用量

单平台聚焦页面显示剩余额度、已使用比例、20 格剩余额度条、附带接口时区的重置
时间和上次成功拉取时间。上下切换 Codex / GLM，确定切换 5 小时 / 7 天周期。
开机仍进入运动看板，从菜单进入 AI 用量。不包含电脑资源页面或 `/api/system` 请求。

现有保存的 `/api/workout` 地址保持不变，仅将末尾替换为 `/api/codex/quota` 或
`/api/glm/quota`，保留协议、主机、端口和反向代理路径前缀。设备不需要重新配网
或保存平台凭据；平台凭据仍由后端管理。

各平台在任何页面均独立地每分钟刷新，失败后 30 秒重试；运动每 5 分钟刷新。
开机联网、重新连接和手动同步会立即请求运动及额度数据，请求耗时可能使下一次刷新略有延迟。
工作任务每轮只执行一个请求，
使配网指令能在请求之间处理。单个平台或运动请求失败不阻断其他接口。缺失周期
显示 `--`，有效零表示额度已用尽；未知重置时间显示暂不可用。超出可打印 ASCII
子集的套餐名称会被省略，不因此拒绝数据。

各平台有独立的版本、来源和 CRC 校验的 NVS Blob（`codex`、`glm`）。无效或更旧
的响应保留该平台上次有效数据。断网、重启后无限期保留快照，并明确显示旧数据。
提交失败仍显示已拉取数据，在后续成功拉取时重试保存；相同快照不重复写入。
更换服务器隐藏旧来源快照，清除设置保留快照。运动 / AI Blob 格式与分区保持
兼容；新网络历史格式按上述规则继承旧单组配置，可通过兼容的分段更新保留配置。

## Codex 任务与审批提醒

从页面菜单进入 **Codex 任务**。审核通过的浅色布局每次显示一个任务，包括项目、
标题、状态、当前步骤、记录用时、最后同步和页码。上下切换，确定打开详情；后端
优先级排序变化时按任务 ID 保持当前选择。后端最多返回三个任务，详情提示省略数量。
标题超出详情四行时滚动显示完整内容。启动仍进入运动首页。

从已保存的运动 URL 派生 `/api/codex/tasks` 和 `/api/codex/alerts`，保留域名、端口
和反向代理前缀。两个接口分别每五秒轮询，HTTP 超时三秒，结果独立于运动和额度。
五个接口共用现有网络任务，每轮最多执行一次请求；两次运动 / 额度请求之间给监控
两个执行机会，两组内部各自轮转，避免某项失败导致其他接口长期无法同步。
慢请求和 HTTPS 校时可能延后轮询，端到端延迟仍需真机测量。
监控接口不存在时三十秒后重试，其他失败十秒后重试。任务页同步失败时按确定只请求
监控接口重试。

版本 1 解码器检查有界 UTF-8 响应、31 位 revision / 游标、三个任务及每页五条提醒。
格式、大小、版本或 revision 回退错误保留此前的内存快照。Wi-Fi 断线、后端失败、
电脑离线、后端 `fresh=false`、审批未知或快照超过十五秒未更新时明确显示非实时。
不会因为任务安静而判定结束。用时根据 API 时间戳和接收后的单调时钟估算，电脑与
后端时钟差异可能影响结果；无效或倒序时间显示 `--`。结束 / 中断仅表示回合停止，
不代表用户需求已成功完成。

首次连接和设备重启时不带 `after` 读取提醒，静默建立基线；已有审批请求仍显示在
任务状态中。短暂断线保留游标，`has_more` 时继续补读。只有新的 `requested` 且
`fresh=true` 提醒才会亮屏，并在当前页面上打开琥珀色提示。游标顺序和有界的近期
ID 集防止重复提醒。五条通知队列已满时，不推进尚未接收的游标。已结束、已取代、
未知和失效提醒静默推进游标。410 或 stream 改变时重新建立基线并刷新任务；切换或
清除服务器会丢弃旧来源与排队提醒。

确定或长按确定只关闭提醒并返回原页面，不批准、不拒绝，也不向 Codex 上报决定。
审批标记由后端后续状态更新清除。更新的快照能关闭已结束、已取代或未知的提醒；
断线、之后的同步失败或实时性失效也会关闭提示。超过十五秒的排队提醒不能唤醒。
有效新提醒重置原有三十 / 六十秒背光策略。任务、游标和通知仅保存在有界内存，
不写 NVS；重启建立新的静默基线。运动、额度和网络存储格式保持兼容。固件不会修改
电脑上的采集 Hook、信任设置或后端凭据。

动态项目、标题、步骤与摘要使用同字号的 12 / 16 px 中文后备字体。未覆盖或超出行高
的字符明确显示 Unicode 编码。列表和提示用省略号截断，详情可查看完整的受支持标题。
读取接口遵循后端可信局域网部署约定，公网部署需要单独设计身份认证。

## 验证与真机验收

运行 `./tools/validate.sh`。静态门禁覆盖导航、日期、URL 边界、CRC 和存储提交失败。
固件门禁还使用 ESP-IDF 的真实 cJSON 测试解析器，并用 LVGL 9.5 渲染实际界面、字体
和二维码；以 24 KB LVGL 内存池验证反复切页和二维码释放。这些属于软件检查，
不能证明整板时序、Wi-Fi 范围、功耗或实际屏幕效果。

门禁还覆盖历史容量、去重、迁移、独立选择、提交失败、重试与等待时序、UTF-8
解析，以及真实工作任务的故障注入：迟到的 DHCP / 断线事件、手动切换失败恢复、
丢失 IP、配网暂停轮询、来源缓存失效与选择保存重试。LVGL 渲染覆盖网络入口、
列表、翻页、长名称、中文、未覆盖字符、离线恢复、存储失败和服务器失败，仍使用
同一 24 KB 内存池。主任务栈设为 8 KB，为启动阶段的历史 Blob 读取与
嵌套校验保留空间；联网任务仍使用 7 KB 栈。真机需检查最小剩余堆与栈水位。

门禁还覆盖额度 URL 推导、CRC 与平台隔离、提交失败、真实 cJSON 解析，以及两家
平台、周额度、额度用尽或缺失、未知重置时间、离线数据和平台不可用的 LVGL 渲染。
真机验收需覆盖这些状态、平台与周期导航、五项菜单、真实接口、断网重启与断电
写入。检查中文字形，观察反复请求和配网时的堆及任务栈情况。

Codex 检查覆盖真实后端响应样例、格式与重复字段、UTF-8 / 版本 / 大小 / 数量边界、
游标基线 / 补读 / 过期、通知队列背压、来源切换、独立调度、旧数据、按 ID 保持选择，
以及实际应用的本地关闭 / 唤醒 / 按键回调边界。LVGL 渲染覆盖任务 / 详情、审批 /
未知 / 结束 / 中断、离线 / 失败 / 空列表、动态中文、未覆盖字形及完整标题滚动，仍
使用 24 KB 内存池。真机仍需验收真实采集事件、中文与圆角边界、跨页亮屏、去重、
重连与 410 恢复、切换来源、接口失败、实际延迟，以及监控运行时的堆 / 栈水位。

真机需要验证两个二维码、手动连接、密码错误恢复、路由器不可用、获取 IP、后端
200 / 502 / 超时、缓存写入错误提示、断网重启、保存期间断电、更换后端、清除
网络和反复进入退出配网。还需测试跨路由器移动、DHCP 超时、历史密码错误、
自动恢复中手动切换及重启后独立选择的持久化。检查中文、数字、所有页面状态和
圆角边界，并记录 Wi-Fi、
HTTP、HTTPS 和手机连接时的剩余堆/最大连续块。刷入成功不等于这些检查通过。

完整更新使用验证过的合并镜像。合并刷入可能重置 NVS；保留配置和缓存需要兼容的
分段刷入。遵循[固件数据策略](../development/engineering/firmware-layout.zh_CN.md#烧录与已存数据)。
